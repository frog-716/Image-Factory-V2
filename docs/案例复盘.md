# 真实案例与复盘

> 品牌与客户信息在 public 仓库中脱敏。这里记录方法和判断，不公开原始商业素材。

## 证据分层

本机保留的首轮原始资料证明：已有手动链路产生3张结果并完成采用/淘汰，但候选差异过小，且其中一张丢失了原标记。这些观察推动了P0方向设计。

下面两个案例的具体方向偏好来自用户提供的发布资料文字摘要，按反馈保留；本次清理没有重新生图或独立复核其完整对照，不能将其作为本地P0新包已完成实测的证据。

## 案例 A：鞋类版式方向

同一个真实商品素材生成三个方向：

- A：白底基准。商品清楚，但展示价值有限。
- B：硬几何色块。结构整齐，但视觉过于呆板。
- C：流动留白与轻阴影。更有设计感，同时没有明显破坏商品，最终采用。

### 得到的结论

“三张候选”必须提供不同的设计思路。只改背景色几乎没有比较价值。

## 案例 B：服装换环境

保留人物、衣服与姿态，只改变环境：

- A：基础棚拍。可靠但增量有限。
- B：克制的零售空间。环境和服装融合较好，采用。
- C：窗边环境。空间存在感偏强，显得突兀，淘汰。

### 得到的结论

场景必须服务商品。所谓“更丰富的环境”不天然更好。

## 证据边界

这些反馈支持继续比较设计方向，不能据此证明：
- 提升了转化率；
- 一定通过具体平台审核；
- 已经大规模生产可用。
