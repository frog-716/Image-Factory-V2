# 在飞书写需求，等待完整 Prompt

**阶段A尚未接通，暂未开放日常使用。** 现有任务不会自动生成新Prompt。安全连接和两款真实验收通过后，才启用下面的流程。

## 你需要填什么

在“生图任务”添加一行：

- **任务名称**：方便自己识别的名字。
- **商品、渠道**：选这次的商品和销售渠道。
- **图片功能**：单选“商品看清楚”“穿搭换环境”或“版式有设计感”。
- **选择素材**：选该商品允许用于生图的原图；一次只选一个明确的主输入素材。
- **目标图片数量**：通常是3。
- **自由补充想法**：一句话说明感觉，例如“克制自然的零售空间，背景浅一点，不要抢衣服主体”。
- **任务状态**：待准备。

无需理解或手选26个提示词组件。

## 接通后你会看到什么

保存满足条件的任务后，工作流自动检查商品和素材、读取相关组件，再调用AI。成功时，当前行“智能提示词草稿”出现三个不同方向及可复制的完整中文Prompt，“任务状态”变为“待生成”。原图保留在选择素材的附件里。

校验或AI调用失败时，不应出现半成品草稿或“待生成”状态；按可读提示修正输入。当前安全连接尚未解决，这些行为仍待真实验收。

本轮到这里结束。ChatGPT生图、图片回填和反馈闭环要等用户验收后再开展。旧任务快照和评价保留，不拿旧行改成新任务。
