# 飞书写需求，ChatGPT出图，回飞书选图

阶段A/B/C完整闭环已验收：飞书任务 → AI Prompt → ChatGPT生图 → 飞书选图与反馈。每款三张独立候选由用户本人评价，全部评价后任务已完成。

## 填一次任务

在“生图任务”添加新记录：

1. 填任务名称、渠道、图片功能、目标数量和自由补充想法。图片功能单选“商品看清楚”“穿搭换环境”或“版式有设计感”，数量通常是3。
2. 再选商品和该商品允许用于生图的原图素材，让所需输入同时完整。不要选另一款的素材。
3. 任务状态为“待准备”、最终快照为空时，工作流自动读取资料并生成。
4. 等当前行“智能提示词草稿”出现完整结果，状态变为“待生成”。原图在选择素材的附件里，草稿包含A/B/C三个方向和可复制的中文Prompt。

**先填想法，再补齐最后一个必填项**，确保想法进入这次AI生成。不用选择26组件，不用打开本地工具或找文件包。

## 已经待生成，接着做什么

1. 打开“选择素材”对应记录，点击附件预览，下载已批准原图。
2. 点击“智能提示词草稿”的正文，全选复制完整内容，不只复制屏幕上可见的几行。
3. ChatGPT网页新开独立对话，上传这张原图，原样粘贴完整Prompt并发送。一款商品用一个对话。
4. 要取得**3张独立图片，A/B/C各一张**，不要拼图、分栏或合在同一画布。若仍为拼图或数量不足，在同一对话要求继续完成缺少方向，沿用原图和原Prompt，不回飞书重做草稿。
5. 对照原图看明显商品跑偏；分别保存为“货号-A”“货号-B”“货号-C”。不替用户填采用/淘汰。
6. 回到原飞书任务，展开“7个隐藏字段”，把实际使用的完整Prompt复制到“最终提示词快照”，检查与发送原文一致，再改为“待回传”。补生成指令单独留痕。

**最容易忘的是最后冻结快照。** 尚未真实生成完成时不要提前改待回传；原生草稿保持原样，已有快照不覆盖。

## 回飞书选图与反馈

1. 在“成图与反馈”每图新增一条记录，命名为“货号-A”“货号-B”“货号-C”，上传对应实际生成图。
2. 每条都关联本轮正确生图任务；先把结果、问题标签、喜欢标签和备注留空。不要关联旧任务，也不要上传拼图冒充三张。
3. 打开附件核对A/B/C没串图；三张全部回填后，把生图任务从“待回传”改为“待评价”。
4. 按商品比较三张，由用户本人分别决定采用/淘汰，再写对应记录；备注只记录真实原因。用户委托代拟原因时明确标注，不能把代拟文字当用户原话；不创造标签。
5. 三张均有真实评价后，把原任务改为“已完成”；有一张未评价就保持“待评价”。

**任务状态目前手动修改。** 逐张关联与三图比较仍有重复操作，已记录，未增加自动化。

## 想改一句话

对尚无最终快照的草稿任务，先修改自由想法，再把状态从“待生成”改为“待准备”，工作流会重新生成。等待新的“待生成”状态后再使用。

已经有最终快照时新建任务，旧快照保留。校验或AI失败时任务仍为“待准备”；不要把旧草稿当本次已准备完成的结果，不手动改成“待生成”。

商品事实、原标记及素材可见范围始终优先；有了Prompt也不等于图片已生成。独立张数说明已补入原生AI指令；阶段C复用已有六图，没有重新消耗飞书AI或ChatGPT生图调用。
