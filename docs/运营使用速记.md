# Image Factory 怎么用

## 一句话
填任务 → 拿原图和Prompt → 去GPT做图 → 回来选图

## 第一步：填任务
在 Image Factory V2 多维表里点“生图任务”→“添加记录”。填写：

- **任务名称**：写一个方便自己找到的名字。
- **商品、渠道**：选这次要做的商品和销售渠道。
- **图片功能**：单选“商品看清楚”“穿搭换环境”或“版式有设计感”。
- **选择素材**：选这个商品已经批准使用的原图素材。
- **目标图片数量**：通常填 3。
- **自由补充想法**：补一句想要的感觉，例如希望背景更浅、别抢衣服主体。

保存后，这一行就是一次生图需求。

## 第二步：准备
在 Finder 双击项目里的“飞书准备与回填.command”，菜单选“按当前想法准备新包”，再选刚才的任务。完成后按屏幕显示打开新包，找到原图和 `prompt.txt`。

## 第三步：去GPT
在 ChatGPT 上传新包里的真实原图，复制 `prompt.txt` 全文发送。目标是拿到 3 张不同候选；如果一次只出 1 张，就用同一任务继续补齐。

## 第四步：回来选图
在飞书点“成图与反馈”，每张图单独新增一行，上传对应图片并关联刚才的任务。只有自己确认后才选“采用”或“淘汰”；还没想好就保持“未评价”。

## 我只需要记住
- 一次需求对应“生图任务”里的一行。
- 用批准的商品原图，完整复制Prompt。
- 每张成图单独回填。
- 评价由实际使用的人决定。
