# Public 仓库公开边界

## 可以公开

- 项目问题定义
- 架构与流程
- 脱敏后的飞书界面截图
- 脱敏后的案例判断
- 自己编写的代码与测试
- 公开开源资料的来源与许可
- V1 → V2 的产品复盘

## 默认不公开

- 客户/品牌原始商品图片
- 未确认可公开传播的生成图
- Feishu Base 真实 URL / token / app id
- 本地绝对路径
- `.local/` 写入证据和 record_id
- 业务密钥
- 完整内部经验包中的敏感业务信息
- R 版本交接 ZIP 和阶段中间产物

## 案例图片

`media-candidates/` 是“可公开候选”，不是自动发布素材。
只有确认公开展示权后，才把对应脱敏版本复制到 `docs/media/` 并提交 Git。

如果没有这项确认，README 保留文字案例和脱敏 UI 截图即可。
