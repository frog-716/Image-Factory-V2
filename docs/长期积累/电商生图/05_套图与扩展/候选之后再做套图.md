# 候选之后再做套图

来源：buluslan的Campaign Style Lock与Funnel Set；yang0摄影方向卡只借三方向选择，不借穿越/八宫格。

先选：同一商品同一目标下，让三种表达形成可比较差异。
再扩：胜出后，为主图、场景、细节等不同职责重复使用适量的色板、字体、光线和产品呈现规则。

无需默认十项全锁。含文字时再锁文字体系，没图标就不引入图标规则。
买家问题顺序可供详情参考：这是什么、怎么用、好在哪里、细节怎样、尺寸合不合、有什么真实证据。
源库的七核心/九扩展属于其跨境Listing编排，不能硬套为拼多多或天猫超市必须张数。

延后能力：多SKU换品、变体换色、虚拟试穿、动图、多语言、本地化、用户内容、品牌故事。
开启条件：单图质量已成立，有真实业务需求，足够同款素材，费用/使用范围明确。不能用模型自动换色替代真实在售色证据。
