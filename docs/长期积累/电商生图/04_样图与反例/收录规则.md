# 样图与反例如何收录

一条样例用一页Markdown即可：

- 当时要解决什么：商品、渠道、用途。
- 输入是什么：原图文件与来源；设计参考分开列。
- 起始提示词是什么：链接对应任务快照。
- 最终图：可用原图、选中图、代表性失败图。
- 人怎么选：真实采用/淘汰及原因；没有理由就写未知。
- 学到什么：是观察、推测还是重复验证的规律。
- 哪些不能外传：品牌内部素材和个人数据。

公开仓的漂亮示例先放“参考”，不冠以本项目优秀案例，也不依据点赞、star或作者自称爆款推断商业表现。
不能为了让负例难看而篡改原图片；自造示意必须清楚标注。

首条可用案例：本项目484330三候选。观察到差异小及一张已有标记缺失；用户选B。不要把它写成“已提升点击率”或“实现规模化”。

本目录不要求完整聊天历史，也不要求一线运营填长文。总结由维护者在已有图片与简短反馈上完成。
