# 参考分工与常见失败

## 三种输入，不要混用

商品原图：货号、颜色和可见结构的依据。
设计参考：只借构图/色彩/氛围中明确列出的部分。
已采用成图：可以借方案，但不能替代原图证明商品事实。

## 失败速查

| 实际问题 | 先查什么 | 不要做什么 |
|---|---|---|
| Logo或标记消失 | 是否把no text误用成删原文，是否漏传原图 | 不自动重画品牌字样弥补 |
| 三张几乎一样 | 是否把候选错误当统一套图，是否只允许微小底色变化 | 不用更多相同重试冒充新方案 |
| 商品像贴纸 | 透视、阴影、反光、光向是否与环境协调 | 不认为叠原图就自然 |
| 面料/鞋底变了 | 是否写了未知材质，是否让模型补未展示的部分 | 不从生成图反填商品资料 |
| 漂浮或巨型效果不适配 | 用途是否真是概念海报 | 不因源库好看就当主图 |

来源：三仓编辑/工艺/参考隔离资料；本项目首轮案例。
本表是排查顺序，不是自动判定根因。重复编辑仍需对照原图；无逐轮日志时，不能精确还原每一步的责任。
