# 电商图型分层

来源：yang0/handraw-style固定提交f03971d，EC-001至EC-024；buluslan电商场景路由与funnel-set，提交73abd50。
下面是本项目分类，不代表源库原有优先级。

## 当前可借

- EC-001 单品主图：一眼看清商品。借核心目标；当前鞋仍是双视图输入，不能暗变单角度实拍。
- EC-009 生活方式场景图：让人想象使用场景。当前茄克能先验证保留人物的背景；鞋的双视图不要硬放同一地面。
- EC-010 人物使用图：有真实穿着输入才选，人物/商品的自由度分别说明。

## 有资料后再启用

- EC-002/003：多角度、细节；先有同款同色的真实相应视图。
- EC-005/006：卖点标注、功能演示；先有确认卖点或实际演示依据。
- EC-007/008：参数尺寸、结构解析；先有真实尺寸/结构文件，不能由AI猜。
- EC-014/015：SKU差异、选购指南；先有每个版本的真实图和规格。
- EC-016/017/018/019：FAQ、工艺、认证数据、口碑；政策、工艺、认证、评价只能据实表达。

## 拓展时再借

- EC-004：包装/内容物；不能增加不存在赠品。
- EC-011/012：多场景、使用教程；不能暗示未获证的使用性能。
- EC-013：对比优势；需要可比的证据，不生成假竞品差距。
- EC-020/021/022：品牌故事、新品、促销；只用确认的品牌、上市与活动信息。
- EC-023/024：内容种草、广告主视觉；可更创意，但不能冒充真实用户经历或把概念图当商品事实图。

不把全部图型立即导入运营菜单。一次真实业务新增一个用途，才取出相应模板。
