# 电商生图长期知识区

本目录预定并入项目 `docs/长期积累/电商生图/`。本轮仅在交付包内建好，未写用户仓库。

它是按需查的资料柜，不是每次全部加载的规则，也不是新的飞书业务表。

| 目录 | 存什么 | 什么时候拿出来 |
|---|---|---|
| 01_图型与版式 | 电商图型职责、所需素材与开启条件 | 新增真实图片用途时 |
| 02_风格与配色 | 商品写实与周边设计分工、配色经验 | 已有获选方案，想增加表现风格时 |
| 03_商品保真与编辑 | 参考图分工、文字/标记、未知角度、融合问题 | 真实成图发生具体错误时 |
| 04_样图与反例 | 原图/目标/结果/意见/来源相互对应 | 积累可复用例子、训练新运营时 |
| 05_套图与扩展 | 套图连贯、详情叙事、活动内容、后期动图 | 单张质量已成立后 |
| 06_渠道与事实 | 拼多多/天猫超市的实际版位与规则证据 | 发布适配或经营效果分析时 |
| 07_来源与待核验 | 固定提交、许可、待补飞书内容 | 升级来源或准备实际导入时 |

## 资料怎样变成可用做法

来源参考 → 本项目适配草稿 → 同款素材实测 → 用户确有采用理由 → 才进入日常推荐。
这些是文档阶段标识，不增加业务状态字段。失败不是删除记录的理由；应写清在哪个条件下不适合。

每条知识只需写：解决什么问题、适合哪里、需要什么、不要照搬什么、来源、有没有实际测过。

默认只读与当前任务有关的一条。不能把所有风格/禁令叠成更长的提示词。
