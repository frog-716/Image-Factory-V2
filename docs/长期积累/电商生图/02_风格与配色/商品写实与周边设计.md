# 商品写实与周边设计

来源：yang0图型/画风/色彩分离，EC电商模板的“商品保持写实”；电商做图库的配色/光线与成套一致性。

可复用方法：
- 商品图只证明商品；风格参考只借指定视觉特征。
- 品牌已确认色板优先；没有色板时可以提出设计候选，但不能把候选写成品牌官方规范。
- 画面主次、色块、纹理、插画装饰服务商品，不能盖住商品识别点。
- 背景颜色和光线不能被误用来改商品真实色号。

以后可以积累：干净目录、克制零售、自然窗光、节令图形、写实商品加轻手绘周边。

不直接搬入：288画风全开、艺术家名替代具体设计需求、未测的模型风格激活表、八宫格输出、默认无依据幻化商品材质。

启用条件：具体渠道版位允许这种表达；有目标商品与同色参考；至少有一个真实采用/退回案例。
