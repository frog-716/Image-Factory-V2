# 只收可核实的渠道规则

当前只做拼多多与天猫超市。渠道名用于筛选，不能替代“图片放哪里”的需求。

规则条目需要：平台、具体版位/活动、类目、要求、来源链接或后台截图、核对日期、适用范围。
本轮没有重新查询这两个渠道最新图片发布规范，因此不写尺寸、比例、白底和文字数的硬阈值。

源库compliance_check.py列的是amazon/tiktok/shopify/aliexpress/temu，没有覆盖当前两渠道；白度、前景面积、OCR的通过也不等于商品准确或平台审核通过。

参数、成分、价格、促销、认证、销量、消费者评价必须来自已确认资料。AI可以重新组织表达，不补不存在的事实。

经营效果与制作反馈分开：没有真实投放位置/时间/流量口径时，不从图片采用推算CTR或销量；这些数据出现后再评估是否需要扩表。
