# Image Factory V2：当前领域模型

版本：当前领域模型，2026-10-04。以用户已经确认的六张表为准。本轮在保持六表的基础上增加研究建议。未部署新功能，没有新增业务表。

## 业务目标

帮助鞋服电商运营更快找到可用商品素材、组合清楚的创作要求、在 GPT 网页获得可用图片，并从图片反馈中积累经验。每周需求不超过100套；当前只支持拼多多与天猫超市。测试商品为 UNIQLO 484330、482295、488726，已不限于早期童鞋 Demo。

日常路径：选商品与素材 → 选提示词组件并补一句想法 → 复制提示词、上传对应素材到 GPT 网页 → 自己微调 → 回传图片 → 采用或淘汰 → 每周总结。

## 六张表

### 1. 商品库
主字段为「品牌 + SKU号」，不让运营维护另一个商品编号。飞书记录ID留在后台。
保留：品牌、SKU号、商品名称、品类、核心卖点、禁改项、主图参考、商品状态、备注。
主图参考关联素材，避免商品表再存一份同一图片。当前六位货号可能代表款式，不等同于每个颜色尺码规格；测试任务必须选定一个颜色，不能混色当一款生成。

### 2. 素材库
保留：素材名称、关联商品、素材类型、附件、素材来源、视角/用途、场景标签、风格标签、渠道标签、允许用于生图、素材说明。
「素材描述」与「备注」已合并为素材说明。AI素材描述建议只作辅助，不覆盖人工确认内容。
没有「使用授权」字段。已授权素材按本次公司确认入库；未确认身份或来自其他商品的图片先留在采集候选区。
一个素材记录保存一个文件版本。不同颜色分开说明；搭配图和细节说明图不能冒充独立商品角度。

### 3. 提示词组件库
保留：组件名称、组件类型、组件内容、适用渠道、适用品类、风险备注、是否启用、备注；AI风险摘要只作建议。
开源提示词先放候选资料，再提炼组件。不把上游开源仓的生产脚本、模型路由、API密钥要求带入新项目。
外部完整提示词可以作为开发采集素材保存，进入日常组件库时按实际用途整理。长度本身不决定质量，不机械要求所有组件短到失去必要约束。

### 4. 生图任务
「生图需求单」与「生图批次」合并。
保留：商品、操作人、渠道、图片功能、所处版面、场景、风格、目标图片数量、选择素材、选择提示词组件、自由补充想法、AI提示词草稿、最终提示词快照、任务状态、创建时间。
默认三张独立候选，可选择更多；数量是创作目标，不能保证网页工具一次调用完成。禁止用三宫格裁切或重复文件凑数。
AI提示词草稿可以变化。最终提示词快照保存运营出发时确认的文字及选用素材、组件版本信息；它不声称记录了 GPT 内部实际提示词或后续全部聊天。
普通微调不记日志，换商品、颜色、渠道用途或明显创作方向时复制新任务。运营不需额外管理会话表、批次表或快照表。

### 5. 成图与反馈
一张图一条记录。保留：关联任务、图片附件、结果（采用/淘汰）、问题标签、喜欢标签、一句话备注。
尚未评价时留空，空不等于淘汰。已经有「结果」就不再增加「是否采用」这一套重复状态。
业务数据可选：实际使用渠道/版位、明确使用位置、曝光、点击、点击率、订单、数据时间区间及原始证据。多位置/多时段的混合数据不硬拆到一张图；详细多渠道经营数据模型仍待真实案例，不趁本轮增加第七张表。
AI问题归因建议与人工反馈分开。没有逐轮修改记录，不能把成图好坏直接归因为某个提示词组件。

### 6. 周度总结
一周一条。保留周编号、起止日期、任务数、已回传图片数、已评价图片数、采用图片数、采用率、高频标签、典型图片、AI周度总结、人工补充。
没有「状态」字段。运行日志与失败提示留在维护侧。
采用率口径：采用数 ÷ 已评价数；分母为零显示暂无。未回传的图片与未填写的反馈不编造统计。此前「生成图片数」仅在能核实全部生成结果时使用，默认统计已回传图片。
先查明确时间范围的数据并计算数字，再让飞书工作流/智能体写总结。AI不自行补算缺失数据。

## AI、Codex 与 Gemini

Codex负责开发维护和本次资料采集、提示词整理，日常生成不依赖Codex。
飞书AI字段可以生成草稿、标签建议；关联推荐先小测，失败就放弃并使用人工筛选。
Gemini本轮负责资料定稿与编排；不能将未下载、未测试或未核实内容包装成已完成。

## 外部方案研究与实现边界

保持已确认六表。实际字段名以阶段0至3回执为准，例如「品牌与货号」「货号」「视角与用途」「智能提示词草稿」「智能周度总结」。上面的AI建议能力为规划，不表示字段已经配置自动生成。

新增的是任务中的三类信息划分，不增加表：
- 商品事实：不能由设计方案覆盖。
- 当前素材限制：缺什么就不补什么。
- 本次创意：可在新任务里变化的背景、版式、留白、环境。

本轮建议先整理三个具名常用做法，让运营选做法而非手工选择17至19个组件；先比较三候选，再将胜出方向扩成一致套图。详见ADR-023至026。

这些为研究建议，未在飞书部署。第4份指定飞书资料只读到“指南和画廊”外壳，不能进入已证实知识。

## 当前实现补充

三做法与新建/复制本地请求的原图准备、想法进入新草稿和历史保护已完成离线验证；飞书新任务触发与回填映射仍未接通。周度总结与AI建议为规划，不能按已部署功能使用。商品公开传播权限独立于用于生成的权限。
