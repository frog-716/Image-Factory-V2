# 日常使用流程

普通运营只需要理解两个动作。

## ① 准备生图

选择：
- 商品
- 渠道
- 图片用途
- 已批准素材
- 一个创作做法
- 可选的一句话想法

得到：
- 实际原图
- 完整 Prompt
- A / B / C 三个不同方向

## ② 回来选图

每张生成结果单独记录：
- 采用 / 淘汰
- 最主要的问题标签（可选）
- 喜欢的点（可选）
- 一句话备注（可选）

微调聊天不做完整日志。

## 当前为什么仍然人工去 GPT

当前业务量不大，质量与连续交互的价值高于无人值守吞吐。
先验证创作方法，再决定是否继续自动化。

## 当前本地入口与配置

已有本机使用`out/p0/打开使用.html`领取两款包，或运行`python scripts/prepare_p0.py --interactive`重新选做法并补一句想法。macOS可双击`准备新包.command`。这只准备本地文件，不触发GPT或飞书；再次准备创建独立目录，不改旧快照/反馈。

公开克隆不包含原图及真实资源。在有素材使用授权的本机，准备被Git忽略的`private/p0-sources.local.json`：顶层为`assets`、`tasks`、可选`base`及`evidence`。每个素材须包含`sku`、`file`、`canonical_file`、`sha256`、`filename`、`colour_code`、`colour_name`、`allowed`、`record_id`，以及人工核实的`material_record`和`product_record`。产品货号、素材关联与批准状态必须一致，原图必须存在并通过哈希/解码校验。该清单是本地批准输入，不等于实时远端读回。

本机现有配置已迁移，日常无需重填。公开测试用`tests/p0_fixture.py`生成的中性合成数据说明接口，不把它当业务素材或真实商品图。

## 飞书最小接通入口

在现有已配置本机双击根目录`飞书准备与回填.command`，或运行`python scripts/connect_feishu.py interactive`。

1. **新建或复制任务**：选商品、做法、渠道，补一句想法。复制只带创作输入，旧快照和旧反馈留在原任务。
2. **准备**：脚本读取飞书当前想法，下载并核验已批准原图，回写智能提示词草稿，生成带真实新任务ID的本地包。直接在飞书新建/复制时，图片功能单选“商品看清楚”“穿搭换环境”或“版式有设计感”；选择对应商品、素材、渠道，目标数量3。
3. **拿包去GPT**：结果中给出新包目录；打开其中`打开使用.html`领取原图与完整Prompt。修改飞书自由想法后，再手动选择“按当前想法准备新包”；旧包不覆盖。
4. **确认实际使用**：真正把这一份Prompt交给GPT后，选择“确认已使用这份Prompt”，首次保存快照。确认前不会填快照；已有不同快照时禁止覆盖，要复制新任务。
5. **逐张回填**：选择实际使用的包版本、生成图文件和判断。每图新建一条反馈，关联包里的新任务，上传后下载核验文件；未评价可留空。同一图重复回填会停止，不覆盖旧反馈。

这里“智能提示词草稿”是现有文本字段，内容由核实素材、固定三做法及自由想法本地组装；未调用AI推荐、生图API或飞书LLM。没有后台监听，不自动生成队列。

“智能创意建议”“智能图片检查”是另外两列实验输出，自动更新关闭，尚不适合直接生产采用。现有准备脚本不会读取这些AI建议，不把它们自动写进Prompt、使用快照、采用/淘汰或人工标签。实验范围与结论见[飞书AI小实验](飞书AI小实验.md)。

公开克隆需自行准备被忽略的`private/base.local.json`：`base`包含`base_token`与可选`url`，`tables`按六个表名映射`id`、可选`view_id`。沿用既有`lark-cli --as user`登录，不在脚本里保存凭证。素材清单仍使用上文的现有配置；每次远端准备重新检查关联、授权、文件字节和启用组件。

维护侧也可使用以下命令。占位词须换为本机输出，真实ID只保存本地，不粘贴进公开文档：

```bash
python scripts/connect_feishu.py new --sku 484330 --method catalog-design --idea "宽留白"
python scripts/connect_feishu.py copy --source 新任务或旧任务ID --method wear-environment --idea "克制零售空间"
python scripts/connect_feishu.py prepare --task 新任务ID
python scripts/connect_feishu.py prepare --task 新任务ID --idea "补充流动元素与轻阴影"
python scripts/connect_feishu.py used --package 本地包目录 --confirm-used
python scripts/connect_feishu.py feedback --package 实际使用包目录 --file 生成图路径 --result 采用 --note "你的真实判断"
```

真实验收已完成新建/复制、想法变化、新草稿、原图包及新任务关联。由于本轮没有收到真实生成图路径，回填验收上传的是明确标注“链路验收、非生成结果”的界面截图，采用/淘汰留空；它只证明附件及关联可用，不算新成图、采用案例或经营效果。

写入之前保存请求与操作记录。超时、部分响应或读回不符时停止；先查看本地记录并只读对账，不自动重发。失败后已有任务/反馈ID仍保留，不为重试再创建同名任务。Base接口无条件版本锁，多人同时编辑同一行仍需协调；脚本会在写前重读检测已发生的变化，但不能保证消除写入瞬间的并发冲突。
