# 使用流程

当前阶段A/B/C完整MVP已验收：飞书任务 → AI Prompt → ChatGPT生图 → 飞书选图与反馈。六张独立结果均正确关联原任务，用户本人逐张采用/淘汰，两条任务已完成。真实验收结果见[STATUS](STATUS.md)。

Stage D已用新安全任务验收三图回填与比较：按钮预建三条已关联反馈，分别上传、本人评价齐全后自动完成。原Prompt Composer未修改。

## 运营怎么操作

在“生图任务”新建一行，先填名字、渠道、单选图片功能、目标数量和自由想法，再选择商品与其获准素材。状态为“待准备”，最终快照为空；补齐最后一个所需输入后触发工作流。

图片功能固定单选：商品看清楚、穿搭换环境、版式有设计感。目标数量通常是3。自由想法可以写“克制自然的零售空间，背景浅一点，不要抢衣服主体”。

等待“智能提示词草稿”出现完整内容、状态变为“待生成”。在这一行看想法与Prompt，从选择素材查看真实附件。无需Terminal、启动脚本、Finder、ZIP、本地任务ID或Python拼装。

无最终快照的任务修改想法后，重新进入“待准备”即可重做。已有最终快照时新建任务，不覆盖旧快照。失败时保持“待准备”，旧的完整草稿可能仍在，不能当成新结果；不手动补成“待生成”。

## 从待生成到待回传

确认状态待生成、草稿完整、最终快照为空。打开选择素材对应记录并下载附件中的已批准原图；点击草稿正文，完整复制全部文字。ChatGPT网页为该任务新开独立对话，上传原图，原样粘贴完整Prompt再发送。

目标是**3张独立图片，A/B/C各一张，不要拼图、分栏或合在同一画布**。此次实际观察到茄克首轮三栏拼图、补生成只得到两张，鞋首轮只得到一张。不足时在同一对话继续完成缺少方向，沿用已有原图与完整Prompt；不重新调用飞书AI。按用户反馈，仅追加上述数量要求到原生AI指令，未改变其他节点或当前两条草稿；新指令尚未新增AI调用复验。

取得独立候选后逐张对照原图检查明显错误。服装看原商品、原模特、姿势与已见结构；鞋看素材颜色、原组合布局、原标记及未知视角边界。保存三张清楚命名的图片，不填采用/淘汰。

回到同一飞书任务，展开隐藏字段，把实际使用的完整Prompt复制到最终提示词快照。读回确认与发送原文一致且草稿未改变，再把状态改为待回传。补生成指令在内部记录中单独留存；已有非空快照不得覆盖。本轮两款均已完成上述真实操作。

## 从待回传到已完成

在本轮“待回传”生图任务点击“三图回填”按钮“建立ABC反馈”。原生非AI工作流先查该任务已有反馈，只有0条时才新增A/B/C三条；名称自动带方向与任务名，关联任务引用当前真实记录。已有部分反馈时也不会补建或覆盖，先核对已有记录。

打开“成图与反馈”的“③ 同任务三图｜比较与评价”，将关联任务筛选选成本任务一次。画册保留图片名称、附件、任务、结果与可选备注，隐藏两列标签但不删除数据。附件封面适应全图；1280宽桌面已实测三张同屏，窄屏会换行。

依次打开每张卡片详情，上传该方向独立图片，核对附件和任务。上传仍是三次，不能一次上传后自动拆分。返回画册比较，打开各张详情填写本人的采用/淘汰；原因可选。备注只记真实原因，委托代拟时标注来源，不创造标签；旧反馈与快照不覆盖。

另一条非AI工作流在结果填写后检查：同任务总反馈恰好3条、有附件且有评价的反馈恰好3条、匹配任务恰好1条、任务状态为待回传或待评价。全部成立才只写任务状态“已完成”；未齐全保持原状态。任务查找使用关联任务的名称，任务名称应唯一；最终更新的是查找到的真实记录。任务重名时不会随意选一条完成。

Stage D新测试任务沿用用户再次明确授权的同三张茄克图评价A/C采用、B淘汰。实际1/3、2/3评价时未完成，3/3后自动已完成；已完成任务再次点击按钮未新增反馈。旧两条验收任务及旧反馈未改，草稿与冻结快照读回逐字一致。

## Prompt Composer保留五步

| 步骤 | 读取或写入 |
|---|---|
| 1. 条件触发 | 商品、渠道、图片功能、选择素材非空；状态待准备；最终快照为空 |
| 2. 查找商品 | 按当前关联商品查找，商品状态必须可用；取得名称、品类、卖点、禁改项、状态与货号 |
| 3. 查找素材 | 按当前选择素材查找，允许用于生图、关联商品匹配且附件非空；取得名称、视角用途、说明、授权与关联商品 |
| 4. AI生成文本 | 传入以上商品、素材资料和任务渠道、功能、数量、自由想法；原生AI生成完整结果 |
| 5. 更新当前任务 | 仅写“智能提示词草稿”和“任务状态＝待生成”，最多更新触发的这一条记录 |

商品或素材找不到合格记录时停止后续节点。AI节点完成后才执行单次写回；失败不会先写一段半成品。当前工作流不读取26组件，不使用AI Agent，也不调用外部HTTP模型。

Stage D只另增两条各六节点的非AI工作流：按钮触发、查已有反馈、条件判断、创建A/B/C；评价触发、查同任务反馈、查附件与评价齐全记录、查唯一任务、条件判断、仅改状态。没有改Composer、自动生图或新增业务表。

## Prompt的内容与边界

输出A/B/C三个明显不同方向，加一份“公共约束＋三个背景方案”的完整中文Prompt。方向从场景、版式、背景光线、色彩或视觉语言变化，公共约束只写一次。

Prompt须包含货号、素材颜色、渠道、图片功能、数量及Logo/原标记保护；只使用已选素材可见范围。鞋保留侧面/上视组合原布局，不合并配对，不补鞋底、后跟、内部或穿着视角。服装保留原模特面部、姿势、衣服和原正面视角，不补背面、内部或画外结构。

构图只能改变背景留白或原图整体位置，不能转动、重摆商品或人物。用户想法不冲突时采用，冲突时保留商品事实。不猜材质、参数、性能或功能，不新增认证或营销信息。

阶段A原生AI输出和阶段B六张独立候选均经过实际检查；这不代表所有未来输出、生图效果或一次三张的稳定性已证明。

## 模型与额度

阶段A通过Computer Use核对实际“AI生成文本”节点及更多设置：没有模型名称或模型选择入口，不能直接选择DeepSeek。使用平台内置节点，不猜它的模型名称。

阶段A实际查看时，租户是飞书基础免费版。权益页显示AI通用额度0点/0点；自动化总额度200次，来源“免费赠送”，已用8次/200次，剩余192次。阶段B复用现成任务，运行日志仍为原有8次，新增飞书AI调用0次；实际次数与范围见[STATUS](STATUS.md)。没有购买、充值、外部API Key或自建Secret。

Stage D新增AI调用0次、ChatGPT商品图生成0次；运行日志实见三图创建1次、评价完成检查3次，共4次非AI原生工作流运行。没有重新查看当前权益余量，不能把阶段A剩余192次当成现在余量。外部HTTP API、AI字段备用方案与Agent均未配置。
