# 使用流程

当前阶段A使用飞书原生“工作流＋AI生成文本”。任务→完整Prompt→智能提示词草稿→待生成；通过后停止，等待用户验收，不自动进入ChatGPT生图或图片反馈闭环。真实验收结果见[STATUS](STATUS.md)。

## 运营怎么操作

在“生图任务”新建一行，先填名字、渠道、单选图片功能、目标数量和自由想法，再选择商品与其获准素材。状态为“待准备”，最终快照为空；补齐最后一个所需输入后触发工作流。

图片功能固定单选：商品看清楚、穿搭换环境、版式有设计感。目标数量通常是3。自由想法可以写“克制自然的零售空间，背景浅一点，不要抢衣服主体”。

等待“智能提示词草稿”出现完整内容、状态变为“待生成”。在这一行看想法与Prompt，从选择素材查看真实附件。无需Terminal、启动脚本、Finder、ZIP、本地任务ID或Python拼装。

无最终快照的任务修改想法后，重新进入“待准备”即可重做。已有最终快照时新建任务，不覆盖旧快照。失败时保持“待准备”，旧的完整草稿可能仍在，不能当成新结果；不手动补成“待生成”。

## 原生工作流只有五步

| 步骤 | 读取或写入 |
|---|---|
| 1. 条件触发 | 商品、渠道、图片功能、选择素材非空；状态待准备；最终快照为空 |
| 2. 查找商品 | 按当前关联商品查找，商品状态必须可用；取得名称、品类、卖点、禁改项、状态与货号 |
| 3. 查找素材 | 按当前选择素材查找，允许用于生图、关联商品匹配且附件非空；取得名称、视角用途、说明、授权与关联商品 |
| 4. AI生成文本 | 传入以上商品、素材资料和任务渠道、功能、数量、自由想法；原生AI生成完整结果 |
| 5. 更新当前任务 | 仅写“智能提示词草稿”和“任务状态＝待生成”，最多更新触发的这一条记录 |

商品或素材找不到合格记录时停止后续节点。AI节点完成后才执行单次写回；失败不会先写一段半成品。当前工作流不读取26组件，不使用AI Agent，也不调用外部HTTP模型。

## Prompt的内容与边界

输出A/B/C三个明显不同方向，加一份“公共约束＋三个背景方案”的完整中文Prompt。方向从场景、版式、背景光线、色彩或视觉语言变化，公共约束只写一次。

Prompt须包含货号、素材颜色、渠道、图片功能、数量及Logo/原标记保护；只使用已选素材可见范围。鞋保留侧面/上视组合原布局，不合并配对，不补鞋底、后跟、内部或穿着视角。服装保留原模特面部、姿势、衣服和原正面视角，不补背面、内部或画外结构。

构图只能改变背景留白或原图整体位置，不能转动、重摆商品或人物。用户想法不冲突时采用，冲突时保留商品事实。不猜材质、参数、性能或功能，不新增认证或营销信息。

原生AI输出经过本轮两个样本检查；这不代表所有未来输出或生图效果都已证明稳定。

## 模型与额度

通过Computer Use核对实际“AI生成文本”节点及更多设置：没有模型名称或模型选择入口，不能直接选择DeepSeek。本轮使用平台内置节点，不猜它的模型名称。

租户是飞书基础免费版。权益页显示AI通用额度0点/0点；自动化总额度200次，来源“免费赠送”。本轮页面已用8次/200次，剩余192次；实际调用次数与范围见[STATUS](STATUS.md)。没有购买、充值、外部API Key或自建Secret。

外部DeepSeek HTTP API不是当前MVP必需项，本轮禁止实施。AI字段自定义自动填充仅在工作流节点不能完成需求时再试；本轮原生工作流可以完成，不启用备用字段。AI Agent只记录为未来周度方案，未配置。
