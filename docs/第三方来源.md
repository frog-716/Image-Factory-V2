# 第三方来源与许可

本项目研究并吸收过以下公开项目的方法：

## buluslan/gpt-image2-ecommerce

用途：
- 电商图片场景分类
- Prompt 分层组织
- 商品编辑与保真思路
- 套图一致性与质量检查思路

许可：MIT。公开仓使用时保留原作者许可文本和来源说明。

## yang0/handraw-style

用途：
- 用“编号 / 画廊 / 完整做法”降低普通人的视觉表达门槛
- 电商图型与构图分类
- 风格、版式、色彩分开管理的产品思路

该项目许可要求保留作者 `yang0` 与原仓库地址：
https://github.com/yang0/handraw-style

## JeremyGDM/awesome-ai-product-photography-prompts

用途：
- 商品事实优先
- 一张图只完成一个明确任务
- 白底、细节、生活场景等商品摄影模板

许可：CC0 1.0。

## 使用原则

本仓不整套复制上游系统。
只保留对本项目当前 MVP 有价值的方法、引用和必要许可。
