# Public发布安全门

本次发布已获用户明确授权。安全门检查公开Git暂存区的实际字节，而不是仅依赖工作区删除或`.gitignore`。高风险项必须全部为0；扫描命令为`python scripts/check_public.py`。

| 安全项 | 公开处理 |
|---|---|
| 密钥与登录资料 | 不提交环境文件或凭证，代码不内置密钥 |
| 飞书真实URL、资源ID、写入证据 | 真实配置在被忽略的private，完整内部回执不提交 |
| 本机绝对路径 | 启动器与代码使用相对位置；本机Python路径仅存在本地私有文件 |
| 业务原图与生成图 | 不提交，两张商品案例候选图也因未获公开授权而不发布 |
| 截图 | 只准许两张已逐图检查的脱敏UI截图，扫描时验证其固定SHA256 |
| 架构配图 | 用户授权公开的流程示意图，逐图检查无业务照片或私有标识，扫描时验证固定SHA256 |
| 交接包与阶段产物 | 项目外可恢复归档，实际P0包本机保留但被Git忽略 |
| 大文件与未审查二进制 | 暂存文件超过1MiB或媒体不在允许清单时阻止发布 |
| 第三方许可 | MIT原文、yang0署名要求及原文、CC0来源声明均保留 |
| 历史 | 旧历史含交接包和真实配置，bundle及工作树完整备份后建立干净main；旧历史不推送 |
| 功能与事实 | 18项离线回归；新飞书连接未接通，成图效果与经营收益不作已完成承诺 |

扫描结果和最终提交清单保留在本地发布证据；提交前及push前均应运行检查。仅推送main，不推旧引用、旧标签或备份包。不创建Release或自动化工作流。
